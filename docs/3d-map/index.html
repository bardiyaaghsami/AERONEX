About this data

Source: map_cloud.ply exported by RTAB-Map after LiDAR+RGB-D run 1 (4,304,293 points). Shown here as 737,847 voxel-centroid points (0.15 m voxels) in the original RTAB-Map map frame, metres, z up. Point colour encodes height only (the export has no colour): a Turbo-style elevation gradient, or monochrome grey.

The optimised trajectory is RTAB-Map's pose graph after the run, at keyframes; it uses loop closures and later information, so it is not online localisation. Its keyframe ATE is ≈ 0.082 m.

Online odometry is drawn as published, in RTAB-Map's odom frame. That frame coincides with the map frame at the start, so the gap that opens later shows the drift that loop closure removed (mostly height). Its online ATE is 0.744 m on the 3,487 common timestamps.

Ground truth is the simulator pose, shown only for evaluation. It is mapped into the map frame with the benchmark's own SE(3) alignment.

Observed-map completeness ≈ 98.0 % within 0.2 m. It is measured against the recorded LiDAR observations, not the whole warehouse. Full method: SLAM report.
